# REEL-0034 Production Brief

## Concept

A Hindi general-education reel explaining "Mood-Congruent Memory"—a cognitive psychology phenomenon where an individual's current emotional state acts as a retrieval cue, making memories matching that valence (e.g., sad memories when down, optimistic memories when happy) significantly easier to recall.

## Audience and takeaway

The audience is adults experiencing emotional rumination or distorted negative recollections during stressful moods. The takeaway is that current mood biases memory retrieval filters rather than providing an objective historical record.

## Format

Portrait 9:16 video, approximately one minute, with Hindi off-screen narration, synchronized Hindi captions, and topic-specific reference visuals.

## Seven-span visual plan

1. Hook: why feeling sad suddenly reminds you of every past failure all at once.
2. Evidence: cognitive psychology research on mood-congruent memory retrieval (Bower et al.).
3. Mechanism: affective associative networks in memory activated by current physiological state.
4. Downward spiral: negative retrieval reinforcing negative mood in a cyclical loop.
5. Cognitive awareness: recognizing that current recall is mood-tinted rather than objective reality.
6. Counter-strategy: waiting for mood stabilization before making broad life judgments.
7. Safety boundary: standard educational disclosure stating content is cognitive psychology education.

## Visual constraints

Use clean, minimalist cognitive memory filter cards and associative node diagrams, lower-third caption-safe area, and no psychiatric diagnostic claims.

## Caption policy

Captions must reproduce the approved Hindi narration, remain bottom-centered, use readable multiline blocks, and avoid rigid rules.

## Evidence and safety gates

Attribute cognitive science to peer-reviewed associative network and memory retrieval studies. Use "retrieval bias" and "mood-congruent recall." Do not claim awareness cures clinical depression.

## Disclosure

State that content is for general educational awareness. The package remains subject to standard repository verification.
