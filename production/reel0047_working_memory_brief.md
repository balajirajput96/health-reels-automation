# REEL-0047 Production Brief

## Concept

A Hindi general-education reel exploring "Working Memory Capacity and Cognitive Load"—the finite workspace of conscious attention (approximately 4±1 distinct chunks), how multitasking and information overload deplete working memory buffers, and how chunking optimizes executive function. It attributes findings to Alan Baddeley, Nelson Cowan, and John Sweller.

## Audience and takeaway

The audience is students, knowledge workers, and professionals feeling mentally overwhelmed. The takeaway is that conscious mental bandwidth is strictly limited to 3-5 active items at once, making external notes and chunking essential for cognitive efficiency.

## Format

Portrait 9:16 video, approximately one minute, with Hindi off-screen narration, synchronized Hindi captions, and topic-specific reference visuals.

## Seven-span visual plan

1. Hook: why trying to remember an OTP, phone number, and grocery list simultaneously crashes mental focus.
2. The Concept: Working Memory as the active mental whiteboard of the prefrontal cortex.
3. Capacity Limit: cognitive research showing working memory holds only about 4 items (chunks) concurrently (Cowan).
4. Cognitive Load & Multitasking: switching tasks evicting working memory items and introducing mental friction.
5. Chunking Strategy: grouping individual digits/concepts into structured units (e.g., 9811-042-315).
6. Offloading: using external checklists, notebooks, and digital tools to free up conscious processing power.
7. Safety boundary: standard educational disclosure stating content is cognitive psychology and neuroscience education.

## Visual constraints

Use clean, graphic working memory slots (4 illuminated buffer slots vs overflowing red dots), lower-third caption-safe area, and no neuro-enhancement promises.

## Caption policy

Captions must reproduce the approved Hindi narration, remain bottom-centered, use readable multiline blocks, and avoid rigid rules.

## Evidence and safety gates

Attribute cognitive science to peer-reviewed working memory models (Baddeley & Hitch, Cowan, Sweller). Use "working memory capacity," "cognitive load," and "chunking." Do not claim brain training raises baseline IQ.

## Disclosure

State that content is for general educational awareness. The package remains subject to standard repository verification.
