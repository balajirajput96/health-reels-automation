# REEL-0075 Production Brief

## Concept

A Hindi general-education reel examining "Cognitive Flexibility and Task Switching: The Cost of Shifting Mental Sets in the Brain"—how the executive control network (Dorsolateral Prefrontal Cortex / dlPFC, Anterior Cingulate, and Basal Ganglia) disengages an existing task rule and configures a new mental set, and the neurobiological reasons why "multitasking" is an illusion that incurs substantial switch costs (reaction time delays and elevated error rates). It attributes findings to Stephen Monsell, Nachshon Meiran, and cognitive neuroscience.

## Audience and takeaway

The audience is students, programmers, multitasking workers, and knowledge professionals. The takeaway is that rapid task-switching forces constant dlPFC rule reconfiguration; mono-tasking in clean sprints avoids switch costs and cognitive fatigue.

## Format

Portrait 9:16 video, approximately one minute, with Hindi off-screen narration, synchronized Hindi captions, and topic-specific reference visuals.

## Seven-span visual plan

1. Hook: why switching rapidly between writing a report and checking messages feels like your brain is constantly stuttering.
2. What Studies Measure: Stephen Monsell's Task-Switching Paradigm measuring "Switch Costs" in milliseconds and error spikes.
3. The Mechanism — Task Set Reconfiguration: the dlPFC must actively suppress previous task rules and load new instructions into working memory.
4. Multitasking Myth: the brain cannot process two complex cognitive tasks concurrently; it rapidly switches back and forth.
5. Metabolic Toll: repeated task set reconfiguration rapidly depletes prefrontal metabolic resources and increases subjective fatigue.
6. The Sequential Batching Solution: grouping similar cognitive activities into dedicated uninterrupted sprints.
7. Safety boundary: standard educational disclosure stating content is cognitive psychology and executive functioning education.

## Visual constraints

Use clean, graphic task reconfiguration diagrams (Task Set A -> dlPFC Rule Inversion -> Switch Cost Latency -> Task Set B), lower-third caption-safe area, and no medical ADHD claims.

## Caption policy

Captions must reproduce the approved Hindi narration, remain bottom-centered, use readable multiline blocks, and avoid rigid rules.

## Evidence and safety gates

Attribute cognitive science to peer-reviewed executive function literature (Monsell, Meiran, Rogers, Posner). Use "cognitive flexibility," "task set reconfiguration," "switch costs," and "executive control network." Do not diagnose ADHD.

State that content is for general educational awareness. The package remains subject to standard repository verification.
