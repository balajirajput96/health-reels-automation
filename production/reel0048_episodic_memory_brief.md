# REEL-0048 Production Brief

## Concept

A Hindi general-education reel exploring "Episodic Memory and Mental Time Travel"—how the brain reconstructs personal autobiographical experiences (events bound in subjective time and place) through hippocampal-neocortical networks, contrasting episodic memory with general semantic facts. It attributes findings to Endel Tulving and cognitive neuroscience.

## Audience and takeaway

The audience is adults interested in memory science and aging. The takeaway is that remembering personal past events is an active constructive process (mental time travel) that also enables imagining future scenarios.

## Format

Portrait 9:16 video, approximately one minute, with Hindi off-screen narration, synchronized Hindi captions, and topic-specific reference visuals.

## Seven-span visual plan

1. Hook: why remembering your 10th birthday feels like "re-living" the moment rather than reciting a fact.
2. The Concept: introducing 'Episodic Memory' by cognitive psychologist Endel Tulving.
3. Episodic vs Semantic: distinguishing personal experiential memories ("I ate cake") from abstract facts ("Paris is a city").
4. Mental Time Travel: subjective autonoetic consciousness allowing simulation of past events and future possibilities.
5. Neural Substrates: the hippocampus binding sensory fragments (sights, sounds, emotions) into coherent memory episodes.
6. Constructive Nature: understanding that memories are actively reconstructed rather than recorded like video files.
7. Safety boundary: standard educational disclosure stating content is cognitive memory neuroscience education.

## Visual constraints

Use clean, graphic mental timeline diagrams (Hippocampal node binding sight, sound, and temporal context), lower-third caption-safe area, and no medical memory cure claims.

## Caption policy

Captions must reproduce the approved Hindi narration, remain bottom-centered, use readable multiline blocks, and avoid rigid rules.

## Evidence and safety gates

Attribute cognitive neuroscience to peer-reviewed episodic memory literature (Tulving, Schacter, Eichenbaum). Use "episodic memory," "mental time travel," and "hippocampal reconstruction." Do not diagnose dementia.

## Disclosure

State that content is for general educational awareness. The package remains subject to standard repository verification.
