# REEL-0064 Production Brief

## Concept

A Hindi general-education reel exploring "Semantic Memory and Conceptual Knowledge Networks: How the Brain Organizes Facts"—how the human brain stores generalized world knowledge, facts, language meanings, and concepts independent of the episodic time/place of acquisition, organizing concepts through spreading activation networks anchored in the anterior temporal lobes and distributed cortical hubs. It attributes findings to Endel Tulving, Allan Collins, and cognitive neuropsychology.

## Audience and takeaway

The audience is students, language learners, educators, and knowledge workers. The takeaway is that semantic memory is an associative relational web; learning new concepts by connecting them to existing nodes (mind-mapping, analogies) builds durable neural networks.

## Format

Portrait 9:16 video, approximately one minute, with Hindi off-screen narration, synchronized Hindi captions, and topic-specific reference visuals.

## Seven-span visual plan

1. Hook: how you instantly know that a sparrow is a bird, can fly, has feathers, and lays eggs without remembering where you first learned that.
2. The Concept: Endel Tulving's distinction between Episodic memory (personal events) and Semantic memory (general knowledge of the world).
3. Spreading Activation Model: Collins & Quillian's network theory—activating the word "Apple" automatically primes "Fruit," "Red," "Sweet," and "Tree."
4. Neural Architecture: the Anterior Temporal Lobe (ATL) functioning as the semantic hub integrating sensory features from visual, auditory, and motor cortices.
5. Abstract Categorization: why humans can recognize a 3-legged chair or an abstract designer chair instantly through conceptual prototypes.
6. Effective Knowledge Building: connecting new concepts to rich existing associations rather than memorizing isolated facts.
7. Safety boundary: standard educational disclosure stating content is cognitive neuroscience and memory science education.

## Visual constraints

Use clean, graphic semantic neural network graphs (Central node "Apple" -> Radiating connection branches to "Fruit", "Tree", "Red", "Nutrition"), lower-third caption-safe area, and no neurological dementia claims.

## Caption policy

Captions must reproduce the approved Hindi narration, remain bottom-centered, use readable multiline blocks, and avoid rigid rules.

## Evidence and safety gates

Attribute cognitive neuroscience to peer-reviewed semantic memory literature (Tulving, Collins & Loftus, Patterson & Ralph). Use "semantic memory," "spreading activation," "anterior temporal lobe," and "conceptual networks." Do not diagnose semantic dementia or aphasia.

## Disclosure

State that content is for general educational awareness. The package remains subject to standard repository verification.
